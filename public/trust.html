This server speaks https with a certificate signed by its own authority. Browsers only trust authorities they know, so they show Not secure until you install this one — once per device. Nothing else changes: your passphrase still never leaves the device, and the certificate only vouches for this address on your own network.

01
Download the certificate
A single file, ae-secure-ca.crt, with no private key in it.
Download ae-secure-ca.crt
02
Install it as a CA certificate
Choose the line for the device you are holding.
AndroidSettings → Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate → pick the file. Your phone will warn that a third party can monitor traffic: that third party is this phone.
WindowsDouble-click the file → Install Certificate → Local Machine → Place all certificates in the following store → Trusted Root Certification Authorities → Finish.
macOSDouble-click → add to System keychain → open the certificate → Trust → Always Trust.
iPhone / iPadSettings → Profile Downloaded → Install (twice), then Settings → General → About → Certificate Trust Settings → enable full trust for “AE Secure local CA”.
FirefoxSettings → Privacy & Security → Certificates → View Certificates → Authorities → Import → tick “Trust this CA to identify websites”.
03
Reopen AE Secure
Close every tab of this site and open it again: the padlock replaces the warning.
